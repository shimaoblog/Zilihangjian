入驻说明

本博客聚合站依托 GitHub 运行，只要你拥有独立博客并提供 RSS/Atom 订阅地址，即可申请入驻。

提交方式

点击下方按钮，跳转到 GitHub Issues 提交入驻信息，管理员审核后会将你加入成员列表，并自动抓取你的博客文章。

需要填写的信息：

  • 博主昵称
  • 博客名称
  • 博客主页链接
  • RSS / Atom 订阅链接
  • 个人简介（选填）
